Protein Layout — select a broad structural category (e.g. SNARE, C2, Ras). This filters the available domains in each protein family.


Domain Name — select a specific domain (e.g. SNARE, Habc, Longin, C2, Arf). Choosing a layout first narrows the list. If left empty, all domain names within the selected layout are included.


Domain Group — choose a classification group for the selected Domain (e.g. SNARE: Qa, Qb, Qc, R).


Subgroup — select one or more groups at the chosen rank to filter sequences belonging to those groups.
Hold Ctrl to select multiple non-consecutive entries. Hold Shift to select a range.
To deselect an entry, hold Ctrl and click it again.
If no group is selected, all groups within the chosen rank are included.
