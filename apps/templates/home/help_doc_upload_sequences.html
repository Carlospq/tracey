Sequences must follow standard one/multiple lines FASTA format

Sequence must contain only common characters, without any symbols such as "-" or "*". It should not contain N's

Header must have 2 mandatory fields and 1 optional field

Fields must be separated by a double vertical bar "||"

First field will be used as sequence shortname (eg. "HoSa_Syx18")

Second field must be the species name as written in NCBI

Extra fields will follow the format "key:value" separated by a ";" (eg. "sourcedatabase:NCBI_refseq; dbxref:NP_005859.1"). NOTE: This fields should not contain semicolons (;) in their descriptions or pattern will be disrupted creating errors in the sequence entry

List of available keys in the extra fields:

  • sourcedatabase: Name of the source database
  • dbxref: ID used in the sourcedatabase for this same sequence
  • foreignannotation: IDs for other databases, if any, and extra description of the protein (eg. "gi|8394376|ref|NP_058626.1| syntaxin 18 [Homo sapiens]-Chromosome 4")
  • aliases: Other names that can be attributed to this protein
  • sequencecomments: Any comment that needs to be added to the sequence
  • gene: NCBI ID for the associated gene, if any
