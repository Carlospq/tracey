Shortname — a compact species code derived from the genus and species name (first two letters each).

HoSaHomo sapiens
MuMuMus musculus
DrMeDrosophila melanogaster
ArThArabidopsis thaliana
SaCeSaccharomyces cerevisiae

The shortname can also include an isoform or protein suffix after an underscore (e.g. HoSa_Syx1). Enter a prefix to match all sequences starting with it — for example, HoSa returns all human sequences.


Scientific name — full or partial organism name (e.g. Homo, Arabidopsis thaliana). Case-insensitive, partial matches are supported.


Aliases — alternative gene or protein names. Type at least 3 characters to see autocomplete suggestions from existing entries in the database. Partial matches are supported (e.g. synapto will match synaptobrevin).


Foreign annotation — free-text search across the external annotation field. Enter any keyword, gene description, or NCBI identifier (e.g. gi|21426793 or putative synaptobrevin). Partial matches are supported.
