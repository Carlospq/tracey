What this feature does

It brings newly added HMM profiles into the rest of TRACEY, in three steps:

  1. Menu sync — scans utils/hmmModels/<FAMILY>/ and adds any .hmm file that is not already represented to the staff protein-family menu (apps/templates/menus/query_sequences_full.py), which drives the cascading dropdowns on Query / Insert / Verify / Features.
  2. Database — walks the updated menu and, for every key without a matching Domaingroups row, creates one linked to its parent Domains / Domaingroups, reading domaingrouplength from the LENG field of the corresponding .hmm file.
  3. MOTIFS.hmmDb rebuild — concatenates every .hmm under utils/hmmModels/ into utils/hmmModels/MOTIFS.hmmDb and re-indexes it with hmmpress -f, so the new profile is picked up by full-database motif scans, not just family-scoped ones.

When to use it

Run it after dropping one or more .hmm files into an existing family folder under utils/hmmModels/ (SNARE, C2, RAS, SM.D1, SNAP, …). A brand-new family needs a new folder and a new entry in DOMAIN_CONFIG at the top of utils/traceySequenceUpdater/updateDomainGroupsWithHMMs.py first, otherwise it is skipped.

How a profile name is handled

The file basename (without .hmm) becomes both the Domaingroups.domaingroupname and the menu key:

  • If it matches (case-insensitively) an existing menu key, or a per-folder alias defined in DOMAIN_CONFIG (e.g. aSnap/cSnap → aSNAP/cSNAP), it is treated as already present.
  • If it is listed in HMM_BLACKLIST it is skipped entirely (for general HMMs that should not get their own menu entry).
  • Dot notation infers hierarchy: Longin.V is nested under an existing Longin key, otherwise added at the top of the family subtree.

Notes

  • The public menu (apps/templates/menus/query_sequences.py) is not touched — if the new domaingroup should be visible to non-staff users, add it there by hand.
  • This feature rewrites the tracked file apps/templates/menus/query_sequences_full.py; that change must be committed to keep it after the next deployment.
  • Requires HMMER3 (hmmpress) on the server's PATH.
  • The same logic is available on the command line as python manage.py UpdateDomainGroups.

When the run finishes, a report listing the added menu keys, the created Domaingroups rows and the MOTIFS.hmmDb rebuild opens in a new tab.
