What this feature does

Uploads a new HMMER3 profile (.hmm) into a protein family and immediately wires it into the site:

  1. The file is validated (must be a real HMMER3 profile, with a LENG line, at most 5 MB) and saved into utils/hmmModels/<FAMILY>/.
  2. The Update Domaingroups sync then runs automatically: the profile is added to the staff protein-family menu, a matching Domaingroups row is created, and the combined MOTIFS.hmmDb database is rebuilt.

The sync report opens in a new tab when it finishes.

Naming matters

The file name without the .hmm extension becomes both the menu key and the Domaingroups.domaingroupname. Use only letters, digits and . _ - (no spaces).

  • Match the family's existing convention, e.g. Longin.VII.hmm — dot notation nests Longin.VII under Longin in the menu.
  • The NAME line (line 2) inside the .hmm file must be identical to the file name without .hmm — motif scanning matches a hit to its domaingroup by that NAME. The upload is rejected if they differ.
  • If the name already matches (case-insensitively) an existing menu key, or a per-family alias, it is treated as already present and no new menu entry / row is created (the file is still saved and included in MOTIFS.hmmDb).
  • A profile name must be unique across all families (motif scanning resolves a hit to a single profile file by name). If the name already exists in another family the upload is rejected with a message telling you which family owns it — to update that profile, pick its family above and tick Replace existing profile; to add a genuinely different profile here, rename the file first.

See the Update Domaingroups help for the full set of naming rules (blacklist, aliases, dot-hierarchy).

Protein family list

Only families that the sync knows how to wire in are listed (the folders configured in DOMAIN_CONFIG). A brand-new family needs a small code change (utils/traceySequenceUpdater/updateDomainGroupsWithHMMs.py) before its profiles can be uploaded here.

Replace existing profile

By default an upload whose file name already exists in the chosen family is rejected. Tick Replace existing profile to overwrite it (use this to update a profile with a newer build).

Notes

  • The uploaded .hmm file and the rewritten apps/templates/menus/query_sequences_full.py must be committed to the repository to survive the next deployment.
  • The public menu (apps/templates/menus/query_sequences.py) is not touched — add the new domaingroup there by hand if non-staff users should see it.
  • Requires HMMER3 (hmmpress) on the server's PATH.
