Infrastructure, monitoring & automated deployment

Date: 01/09/2026

Major updates:

  • Automated CI/CD pipeline (GitHub Actions): every change is linted, checked and tested automatically, and tagged releases deploy to the production server without manual steps
  • Continuous monitoring with Grafana Cloud: server health (CPU, memory, disk), MySQL database activity (queries, connections, traffic, slow queries) and website availability
  • Automated uptime alerting: the team is notified on Slack within ~1 minute if the site or the application server goes down
  • Platform upgraded to Django 5 and Python 3.12 for long-term security support and performance

Minor updates:

  • Two independent availability probes (public site through the web server, and the application server directly) for faster fault isolation
  • Centralized server and database logs for troubleshooting
  • Deployment and monitoring runbooks documented for maintainers
